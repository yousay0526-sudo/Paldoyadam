# 길목 이정표 원화 · 2026-10-28

사용자 요청: 탐식굴로 가는 마을 길의 닫힌 문처럼 보이는 부분을 열고, 원형 이동 표식을 조선시대 분위기의 사물로 바꾼다.

- `village-open-east-generated.png`: 내장 ImageGen으로 기존 마을 원화를 참조해 동쪽 문짝을 지우고 열린 흙길로 편집한 전체 생성 결과. 게임에는 이 전체 이미지를 덮어쓰지 않는다.
- `waypost-generated.png`: 내장 ImageGen으로 만든 투명 목제 이정표/새끼줄/등롱/밑돌 원본. 글씨는 런타임에서 목적지에 맞춰 그린다.
- `scripts/prepare_map_waypoints.ps1 -OriginalVillage <approved-original.png>` (Windows/System.Drawing): main `535a13e`의 승인 원본 해시를 확인한 뒤 x1330..1535, y545..719 안의 생성 편집만 16px 경계 혼합으로 적용한다. 이 범위 밖 픽셀은 동일하다. 이정표는 256×256 RGBA로 축소한다. 원본 입력은 출력 파일과 별도 경로여야 한다.
- 실제 생성 크기: 마을 1536×1024, 이정표 1254×1254. 저장소 입력·출력 해시는 [provenance.json](../provenance.json)에 기록한다.
- 국적/시대 고증의 학술 재현물을 주장하지 않는다. 기존 게임 미술에 맞춘 목제 길안내 소품이다.

## 사용자 검토 반영

- 글자가 작고 얇다는 피드백에 따라 런타임 방향판만 넓히고 Nanum Myeongjo Bold 26, 동굴 표지석 28과 0.6 단위 덧그리기로 획을 보강했다. 글자 폭/높이 맞춤에서 16 크기 붓글씨가 작아지던 문제를 수정했다.
- 마을 동쪽은 배경의 기존 등주에 방향판만 붙인다. 별도 나무 기둥·등롱을 중복 표시하지 않는다.
- 동굴은 `cave-waystone-generated.png` (실제 1254×1254 RGBA)의 청회색 거친 바위로 교체했다. `scripts/prepare_cave_waystone.ps1`은 1280 기준 정규화 크롭을 실제 해상도에 비례 적용하여 256×178 RGBA를 만든다. 처음 1280×1280으로 가정한 준비 실행은 크기 검사에서 중단됐으며 실제 IHDR을 확인한 뒤 수정했다.

## 승인 재질 최종 적용

사용자가 최신 동굴 일체감 시안을 승인하고 다른 이정표도 동일하게 게임에 적용하도록 요청했다. 이전 요청에 따라 별도 로컬 인게임 테스트는 생략하고, 준비된 에셋 검사와 네이티브 빌드·기존 원격 CI를 확인한다.

- `approved-material-review.png` (1785×881): 사용자가 승인한 이미지 시안. 실제 최종 게임 캡처로 표시하지 않는다.
- `approved-material-atlas.png` (1774×887): 승인 시안을 참조해 ImageGen으로 준비한 세 나무판과 동굴 표지석. 목적지 이름을 그림에 포함해 런타임 폰트를 덧그리지 않는다.
- `scripts/prepare_approved_waypoints.ps1`, `approved-preparation.json`: 알파 경계를 자르고 비율을 유지해 축소. `waypost-boards.png`는 1152×100, 왼쪽부터 384×100 셀에 솔바람재/탐식굴/마을. `cave-waystone.png`는 256×178, 마을 음각 포함·화살표/채색 없음.
- 위의 이전 26/28 명조 및 화살표 구현 기록은 검토 중간 단계다. 최종 구현은 해당 텍스트/화살표 그리기를 제거하고 승인 재질 PNG를 표시한다.
