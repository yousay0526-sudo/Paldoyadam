# 무명 통바지와 짚신 · 정지 8방향 디자인 후보

2026-10-23. **1단계 검토용 초안이며 승인본·실행용 에셋이 아니다.** 걷기는 시작하지 않았다.

## 범위와 디자인

- 무명 통바지, 좁은 쪽빛 대님, 흰 버선, 볏짚색 짚신. 기존 검정·금색 장화와 구별되는 천/짚 장비 후보.
- N, NE, E, SE / S, SW, W, NW 순서. 방향 반전·개별 포즈 이동·변형 없음.
- ZIP의 `idle-8dir-guide4x.png`, 관절 JSON, 가림 마스크를 사용했다. 기존 주인공 상체는 제공된 몸체에서 복사했다. 재생성한 상체는 결과에 사용하지 않았다.
- 생성 4회. 선택한 생성 원본은 1774×887이며 그대로 `design-generated-source.png`에 보존했다. 전체 캔버스를 같은 2:1 비율로 3072×1536으로 정규화했다. 실제 4배 해상도 디테일을 생성했다고 주장하지 않는다.
- 기존 몸체 입력에 장화 조각이 남아 있어 가림 마스크 밖의 기존 조각을 합성에서 제외했다. 입력 PNG는 수정하지 않았으며 새 다리 없는 몸체를 만들지 않았다. `reference/`는 제공 파일의 바이트 복사본이다.
- 코드 연결, `src/`, 기존 `assets/`, 속도·프레임 수·전투 판정, 상체 원본, 병합·배포는 변경하지 않았다. GAME_BIBLE은 아직 미확정 디자인이므로 갱신하지 않았다.

## 검사 결과

원본 몸체의 가림 마스크 안 **불투명 보호 픽셀 변경은 0**이다. 반투명 경계는 원본 레이어를 그대로 유지하지만 새 다리와 합성되므로 최종 RGBA 동일성 검사 대상에서 제외했다. 셀 가장자리 2px(192px 환산) 여백은 8방향 모두 통과했다.

아래 IoU는 보이는 가이드 색 영역과 추출한 다리 알파의 비교다. 치마 속 전체 다리 IoU와 같지 않다. 최하단 y는 192px 셀로 환산한 보이는 다리 전체의 alpha≥128 경계다. 접지 범위 175~177은 방향별 외곽 하단에만 적용한 예비 검사이며 두 발 각각의 접지 검사와 같지 않다. **관절 위치를 JSON으로 그대로 복사해서 오차 0으로 기재하지 않았다.** 독립적으로 판독한 관절 랜드마크가 없어 최대 관절 오차와 발별 접지 실패 수는 미측정이다.

## 남은 문제와 복구/후속 작업

1. 생성 시 발목·신발 위치와 부피가 가이드에서 벗어났다. 그림을 이동·비틀거나 가이드를 바꿔 수치를 맞추지 않았다. 정지 포즈별로 가이드에서 다시 그려 좌표를 맞춰야 한다.
2. E의 먼 발이 충분히 드러나지 않고, 일부 짚신 끈이 요구한 독립된 두 줄보다 Y자 형태에 가깝다. 버선코·뒤꿈치 고리도 방향별 추가 검토가 필요하다.
3. 추출 경계에 밝은 테두리, 제공된 가림 마스크 경계 근처에 이전 원화 조각이 남을 수 있다. 가림 마스크/상체 원본을 임의로 바꾸지 않고 후보를 보류했다.
4. 제공 JSON은 정지 두 발을 모두 contact=true로 표시하지만 원근에 따른 발의 화면 y가 다르다. 먼 발의 개별 접지 검사는 Claude의 투영 정의 확인이 필요하다. 이번 결과의 오차를 그 문제로 정당화하지 않는다.
5. 걷기 64프레임·실행용 PNG·90ms GIF·게임 렌더·보행 깜빡임은 미제작/미검증이다. 디자인과 정지 정렬 검수가 통과하기 전 걷기로 넘어가지 않는다.

실패 후보의 원본과 전체 프롬프트를 보존했으므로 같은 정지 가이드에서 다시 제작할 수 있다. 상체·게임 파일을 되돌리는 복구는 필요하지 않다.

## 재현과 회귀 확인

`python scripts/prepare_leg_gear_design_review.py` (Pillow, NumPy 필요). 제공 입력 해시는 `preparation.json`에 있다. 이 스크립트는 후보 PNG 합성/검토 측정만 하며 게임 에셋에 설치하지 않는다.

재현 스크립트를 다시 실행해 생성 PNG 5장과 preparation.json 총 6개 파일의 SHA-256이 재실행 전후 모두 같은 것을 확인했다.

게임 실행 파일이 읽는 경로와 코드가 바뀌지 않아 C/SDL 빌드·게임 실행은 수행하지 않았다. Git 기준으로 기존 `src/`, `assets/` 및 주인공 PNG 무변경을 검사한다. 이번 작업의 결과를 기존 CTest 통과 기록으로 대신하지 않는다.

사용자에게 디자인과 미통과 항목을 함께 보여주는 Draft PR로 보관한다. 승인본·병합 가능 상태가 아니며, 병합·배포·걷기 착수 승인 요청은 하지 않는다.
