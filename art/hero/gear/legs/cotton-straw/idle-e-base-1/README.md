# E방향 재사용 기본형 후보 1

최신 재질 후보는 이 폴더다. 이전 직접 작화 기준은 `../idle-e-grid-1/paint-v4/`이며 기존 기록은 변경하지 않았다. **E 한 포즈의 미승인 재질 연구이며, 정지 8방향 완성본이나 실행용 에셋이 아니다.**

- `comparison.png`: 왼쪽 이전, 오른쪽 재질 보정. 전체 주인공과 다리 확대를 함께 확인한다.
- `master-e.png`, `visible-legs-e.png`: 원래 몸체/가림을 적용한 결과.
- `far-unoccluded.png`, `near-unoccluded.png`, `isolated-feet.png`: 가림 전 두 발. 각각 두 가로 짚끈과 별도 뒤꿈치 고리를 유지했다. 합성에서는 먼 끈 일부가 가려진다.
- `masks/`: 실제 작화 색 영역에서 얻은 무명/쪽빛/버선/짚/윤곽 마스크. 가이드 윤곽으로 만든 마스크가 아니다.
- `geometry-e-alpha.png`: 이전 직접 작화의 알파를 그대로 보존한 E 형상. 발의 이동·변형이나 가이드 변경 없이 재질만 수정했다.
- `palette.json`: 재질 색. 원본 brief의 밝고 어두운 색을 반영하고 잡음 없이 짧은 주름 붓선과 명암 경계를 다듬었다. 원래 상체와의 화풍 조화는 사용자 확인 대상이다.

재현: 저장소 루트에서 `python scripts/prepare_leg_idle_e_base.py` (Pillow/NumPy/OpenCV). 색 변경 연구는 `--palette 경로 --output 새폴더`로 입력한다. 색 변경 시 새 폴더를 요구해 이 후보를 보존한다. 기존 직접 작화 스크립트의 절대 경로를 재사용하며 그 파일은 변경하지 않는다.

같은 체형의 색·천 재질 변형에는 이 분리 구조를 재사용할 수 있다. 신발 종류나 바지 윤곽이 바뀌면 새 원화가 필요하고, 나머지 7방향과 걷기에는 각 포즈의 작화가 필요하다. 이 E 후보 하나가 전체 방향의 자동 제작을 보장하지 않는다.

## 검사와 미해결

실제 출력 PNG에서 띠 RGB 성분 중심과 밑창 알파 하단을 먼저 읽어 `observations.json`에 저장한 뒤, 가이드와 비교했다. 결과는 `validation.json`이다. 보이는 띠 중심은 해부학적 발목 중심과 같지 않을 수 있다. 버선 밝은 면 중심을 뒤꿈치·발끝 관절로 인증하지 않는다. 실제 뒤꿈치·발끝의 중심선 끝점 판독은 아직 미완료다.

원본 `GPT_LEG_ART_BRIEF.md`는 `contact:true`인 두 발 밑창 모두 y176±1을 요구하고, 뒤꿈치/발끝 중심선보다 밑창을 약6px 아래에 두라고 한다. 고정 E 중심선은 먼 발 y166.94, 가까운 발 y172.70이다. 후자에 단순히 6을 더하면 각각172.94/178.70으로 공통 y176 규칙과 일치하지 않는다. 이 차이는 현재 그림을 통과시킬 근거가 아니다.

현재 실제 밑창은 먼 발171.25(공통 화면 바닥 규칙 **실패**), 가까운 발176.75(통과)다. `contact:true`가 원근을 포함한 지면 접촉인지 공통 화면 y인지 확정이 필요하다. 가이드를 고치거나 먼 발을 내리지 않았다. 전체 정지 원화 승인은 **false**이며 사용자 확인 전 다른 방향·걷기·게임 연결·병합·배포로 진행하지 않는다.
