# SE 정지 한 포즈 · 기본형 후보 1

사용자의 다음 진행 지시에 따라 E 다음으로 SE 한 포즈만 제작했다. 이미지가 보이지 않았다는 설명을 E 원화의 시각 승인으로 처리하지 않는다. **SE도 검수 미통과 후보**이며 기존 생성 후보나 E 후보를 교체하지 않았다.

E에서 재사용한 것은 `idle-e-base-1/palette.json`과 같은 색상표 및 경로/짚끈 붓 처리 함수다. 바지와 신발은 SE용 새 절대 좌표 경로로 그렸다. 기존 E 발을 이동·회전·왜곡하거나 가이드 윤곽으로 잘라 맞추지 않았다. 코드 연결이나 게임 에셋 설치는 하지 않았다.

- `comparison.png`: 고정 가이드 / 이전 생성 SE / 새 후보. 전체와 확대를 함께 보여준다.
- `master-se.png`, `visible-legs-se.png`: 원래 몸체·가림 마스크를 적용한 결과. 칼에 가려지는 먼 발과 계단형 가림 경계는 원래 보호 마스크를 보존한 결과다.
- `far-unoccluded.png`, `near-unoccluded.png`, `isolated-feet.png`: 두 발 개별 원화. 각각 분리된 가로 짚끈 두 줄과 별도 뒤꿈치 고리를 유지했다. 합성에서는 먼 발의 일부가 칼에 가려진다.
- `far-foot-only.png`, `near-foot-only.png`: 바지와 분리한 발 원화. 실제 신발 외접 크기/밑창 검사는 이 PNG에서 읽는다.
- `observations.json`: 목표 좌표를 읽기 전에 실제 출력에서 추출한 띠 중심과 신발 외접 상자.
- `validation.json`: 관찰값과 가이드 비교. 외접 상자 길이는 뒤꿈치~발끝 중심선 길이와 같은 측정량이 아니므로 서로 같은 값이어야 한다고 판정하지 않는다.
- `alignment.png`: 고정 가이드의 발목·뒤꿈치·발끝 십자와 공통 화면 바닥선.

재현: 저장소 루트에서 `python scripts/draw_leg_idle_se_base.py` (Pillow/NumPy/OpenCV). 이 후보 경로로 다시 출력한다. 다른 후보 제작 시 별도 폴더를 사용한다.

보이는 실루엣 IoU **0.7317**은 0.75 미달이다. 가림 전 실제 띠 중심 거리 먼0.216px/가까운0.202px. 띠 RGB 성분은 가려진 해부학적 발목 중심의 인증값이 아니다. 뒤꿈치·발끝 중심선 끝점 판독은 미완료이며 최대 관절 오차는 null이다.

실제 밑창 먼174.75/가까운180.00은 공통 화면 y175~177 규칙에 두 발 모두 실패한다. 고정 SE 중심선은 먼 뒤꿈치166.32/발끝169.94, 가까운 뒤꿈치171.52/발끝175.14다. 밑창이 중심선보다 약6px 아래라는 지시와 공통 y176 규칙의 관계는 E에서와 같이 미해결이다. 수치를 맞추기 위한 발 이동이나 가이드 수정은 하지 않았다. 이 모순은 현재 실패를 면제하지 않는다.

사용자 시각 확인, 실루엣, 해부학적 뒤꿈치·발끝, 접지 기준 정리가 남아 있다. 전체 정지 승인=false. 다음 방향은 사용자 확인 후 진행하며, 정지 설정화 검수 통과 및 승인 전 걷기·게임 연결·병합·배포는 하지 않는다.
