# SE 원화 · 회화적 2D 재작화 1

사용자는 메이플처럼 부위별 2D 원화를 조합하되 **기본 주인공의 화풍을 최대한 유지**하도록 제작 방향을 정했다. 직전 `idle-e-grid-1`, `idle-e-base-1`, `idle-se-base-1`의 도형/평면 표현은 사용자가 거부했으며 후속 원화의 미술 기준으로 사용하지 않는다. 해당 파일은 기록 보존만 한다.

이번에는 기존 회화적 SE 후보와 원래 주인공을 참조해 이미지 편집으로 천 주름, 버선 부피, 짚 엮임을 다시 그렸다. 이후 별도 이미지 편집으로 장비만 분리하고 가려진 면을 보완했다. **한 포즈의 화풍 연구**이며 사용자 미술 승인이나 정렬 통과본이 아니다. 두 번째 분리 편집에서 위치/비례가 달라진 문제가 있다.

## 파일

- `generated-source.png`: 전체 인물의 작화 원본. 생성 과정에서 상체도 재해석됐으므로 참고 연구용이며 원래 상체를 대체하지 않는다.
- `generated-legs-source.png`: 장비 분리 편집 원본. 두 발과 주름·짚끈 묘사를 확인한다.
- `paint-reference-se.png`, `style-reference-se.png`: 이전 회화적 SE와 원래 게임 캐릭터의 고정 프레임 참조.
- `prompt.txt`, `isolation-prompt.txt`: 실제 두 이미지 편집 지시문.
- `legs-se.png`: 정사각 원본 전체를 동일 비율로 768px에 정규화한 장비. 개별 발 이동·크기 보정·왜곡·반전 없음.
- `master-se.png`, `visible-legs-se.png`: 고정 몸체·가림 마스크로 원래 상체/치마/칼 픽셀을 복원한 결과.
- `near-isolated.png`, `far-isolated.png`: 분리 원본의 실제 알파 연결 성분. 원화 픽셀 관찰용이며 발을 이동시키지 않았다.
- `preview.png`: 원래 상체에 합성한 모습과 장비 질감 확대.
- `comparison.png`: 이전 회화적 후보 / 사용자 거부 도형 후보 / 새 회화적 원화. 새 결과도 정렬 대기임을 표시한다.
- `observations.json`, `validation.json`, `alignment.png`: 실제 출력 관찰, 고정 가이드 비교, 십자 표시.

재현: 저장소 루트에서 `python scripts/prepare_leg_idle_se_painted_review.py` (Pillow/NumPy/OpenCV). 이 명령은 보존된 두 생성 원본을 다시 그리는 명령이 아니라 정규화·합성·검사/미리보기만 재현한다. 생성 원본 재생성의 동일성은 보장하지 않는다.

## 한계와 다음 작업

천의 중간 명암과 접힌 면, 버선 볼륨, 두 가로 짚끈과 엮인 밑창을 다시 표현했다. 원래 몸체에 합성한 결과의 보호 불투명 픽셀 변경은0이다. 원래 주인공 PNG/게임 코드/에셋/가이드/가림/과거 원본과 검수/sources/는 보존했다.

장비 분리 편집이 고정 프레임의 배치와 크기를 유지하지 못했다. 가까운 띠 관찰 (87.75,159.50) / 먼 띠 (113.00,146.75), 고정 목표 대비 거리11.337/21.667px다. 실제 색 성분을 먼저 읽은 뒤 가이드를 비교했으며 목표를 관찰 좌표로 복사하지 않았다. 보이는 실루엣 IoU0.3471로 미통과다. 밑창 가까운184.25/먼168.00도 공통 화면 바닥 규칙에 실패한다. 원래 가림 마스크와 접합이 불균일하고 먼 발이 높고 오른쪽으로 벌어져 있다. **이 결과를 게임에 넣을 수 있는 정렬본으로 취급하지 않는다.**

기존 띠 검출 함수는 y150 이상만 검색하므로 높아진 먼 띠를 누락한다. 이 연구에서는 분리 알파 성분 각각의 실제 파란 색 영역을 추가 관찰해 먼 띠를 기록했다. 띠 RGB 영역 중심은 해부학적 발목 인증값이 아니며 뒤꿈치·발끝 관절 최대 오차는 null이다. 기존 contact 지시문과 중심선 높이의 관계도 미해결이다. 두 가로 끈은 분리 원화에서 보이며 원래 칼과 합성하면 일부 가려진다.

다음은 사용자 화풍 확인 후 **이 묘사 수준을 보존하며 고정 포즈에 맞춰 다시 작화**하는 일이다. 기존 발을 이동/왜곡하거나 가이드를 바꿔 수치를 맞추지 않는다. 다른 방향·걷기·게임 연결·병합·배포는 진행하지 않았다.
