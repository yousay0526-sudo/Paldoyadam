# 이미지 요청 채팅용 지시문 — 사냥 재료 2종

아래 내용을 새 이미지 요청 채팅에 그대로 전달한다. 이번 경제 시스템 PR은 **두 재료의 이미지 칸을 비워 두고**, 바닥의 이름·수량, 가방의 이름·수량·용도·가격으로 구분한다. 기존 약재·장비·소모품 이미지는 보존했다. 이번 PR에 새 이미지나 임시 원화를 넣지 않는다.

팔도야담의 **가죽 조각·뼈 조각 아이콘 원화와 실행용 PNG**를 제작해줘.

저장소: https://github.com/yousay0526-sudo/Paldoyadam

먼저 GitHub API로 작업 PR의 `docs/HUNT_MATERIAL_ART_BRIEF.md`와 `docs/HUNT_ECONOMY.md` 최신 내용을 읽어줘. main에 아직 없으면 사냥 보상·경제 시스템 PR의 head를 사용해. 기존 이미지 전체 분석이나 소스 전체 검토는 생략해도 돼.

이번 작업은 이미지 제작과 검수까지만이다. 저장·드롭·판매 로직, 수치, 퀘스트, Claude의 브랜치, 기존 약재·HUD 아이콘은 바꾸지 마.

|---|---|---|
| `assets/ui/icon-leather-scrap.png` | 일반 멧돼지 사냥으로 얻는 작고 두툼한 황갈색 가죽 조각. 불규칙한 외곽, 살짝 말린 한쪽 끝, 마른 가죽 결 | 천 보따리·약재 꾸러미처럼 보이지 않게. 끈·매듭·용기 없음 |

공통 규격:

- 실행 PNG: 각 **128×128 RGBA**, 투명 배경. 불투명 배경·바닥·그림자판·테두리 프레임·글자·숫자 없음.
- 128px 기준 사방 최소 8px 투명 여백. 중앙 정렬, 실루엣 점유율 약 75~85%. 두 아이콘의 시각적 크기와 시점·조명 통일.
- 가방 약 24~32px, 바닥 약 18~24px에서도 대상이 읽히도록 큰 덩어리와 굵은 명암 위주. 털·균열 등 미세 묘사가 실루엣을 흐리지 않게.
- 조선풍 수묵·채색 판타지 RPG에 맞는 절제된 손그림. 기존 HUD와 어울리는 따뜻한 색·무광 질감. 현대 UI 아이콘·광택 보석·서양 문장 장식은 피한다.
- 피·살점·상처·젖은 조직 없이 건조한 채집 재료로 표현한다.
- 원본은 각 1024px 이상 투명 이미지로 보존. 프롬프트, 생성 원본, 실행 PNG, 투명도·여백 검사, 작은 크기 검수판을 함께 제공한다.

진행 방식:

1. 두 아이콘을 만들어 각각 원본과 실행 PNG를 준비한다.
2. 18/24/32/128px 비교, 밝고 어두운 배경에서 알파 경계·가독성·두 재료 구별을 확인한다.
3. 두 이미지를 나란히 보여 주고 사용자 승인을 기다린다.
4. **이미지 승인 전에는 게임 연결·main 병합·배포하지 않는다.** 승인 뒤 별도 작업 브랜치/PR에서 위 두 파일을 추가하고, 가방·바닥 재료 표시에 연결한다. 경제 시스템 PR의 빈 이미지 칸과 이름·수량 안내는 연결 전까지 유지한다.
5. 기존 9문 보상, 드롭률·개수·매각가, 퀘스트 약재, 저장 형식·거래·전투·조작은 유지한다.

원본 전달과 적용 코드는 별도 검토 대상으로 구분하고, 실행하지 않은 게임 검증을 통과했다고 쓰지 마.
