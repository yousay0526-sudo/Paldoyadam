# 반복 사냥 기반 1차 — 2026-11-04

솔바람재에 의뢰와 별개인 **일반 멧돼지 최대 6마리**를 둔다. 쓰러진 멧돼지는 솔바람재에서 **30초** 플레이하면 제자리에 다시 생겨 6마리를 채운다. 마을에서 다시 들어오면 새 사냥 회차로 한꺼번에 채운다.
기준 main `fa2647d`(자동저장 PR #51 병합 직후). 게임 버전 0.8.0 그대로, 저장 형식만 v2 → v3.

## 재생성(2026-11-04 사용자 요청)

- 일반 멧돼지가 쓰러지면 그 자리의 재생성 시계가 `HUNT_RESPAWN_SECONDS` **30초**로 시작한다. 같은 지점에는 한 마리만 있으므로 최대 6마리를 넘지 않는다.
- 시계는 흔적 조사를 마친 뒤 솔바람재에서 실제로 플레이할 때만 줄어든다. 일시정지·메뉴·대화·상점, 마을·탐식굴에 있는 동안, 허수아비 수련 중에는 멈춘다. 불러오기는 남은 시간을 그대로 이어 간다. 오프라인으로 흐르지 않는다.
- 시간이 다 되면 출현 지점에서 최대 체력으로 다시 생기고 흙먼지가 인다. 주인공이 그 지점에서 `HUNT_RESPAWN_CLEAR` **420** 안에 있으면 눈앞에 갑자기 나타나지 않도록 주인공이 멀어질 때까지 기다린다. 도착 지점은 모든 출현 지점에서 420 이상 떨어져 있다.
- 다시 생긴 멧돼지도 처치마다 9문만 지급한다. 30초·420은 손맛을 본 뒤 조정할 수 있는 값이다.

## 회차

- 새 회차는 **마을 → 솔바람재 이동** 때만 시작한다. 6마리 모두 출현 지점에서 최대 체력으로 다시 놓이고, 재생성 시계가 지워지며, 회차 번호가 1 오른다.
- 같은 방문 중에는 위 재생성 규칙으로만 다시 나온다. 일시정지·가방·여정·무공 배치·대화, 허수아비 수련장 왕복, 저장 불러오기는 회차를 바꾸지 않고 시계도 되돌리지 않는다.
- 사망하면 기존 규칙대로 마을에서 회복한다. 처치·엽전은 유지되고 살아 있던 일반 적은 제자리·최대 체력으로 돌아간다. 다시 솔바람재에 들어가면 일반 입장과 같이 새 회차다. 백정 재도전은 탐식굴에서 일어나므로 일반 적과 무관하다.
- 의뢰용 멧돼지 3마리의 처치·약재·조사·전달·보고·보상 기록은 회차와 무관하게 유지된다.

무한 웨이브·오프라인 사냥·적 종류 추가는 후속 작업이다.

## 보상

- 일반 적 처치마다 **9문**(의뢰용 멧돼지와 같은 값)을 처치한 같은 틱에 한 번 지급하고 "멧돼지 제압 +9문"을 띄운다.
- 약재 드롭·의뢰 진행·약재 수량 변화는 없다. 의뢰·백정 보상 규칙은 그대로다.
- 뼈·가죽·정혼주·판매·제련·수련 트리·새 증강은 이번 범위가 아니다.

## 저장과 복원

- v3에 회차 번호와 6마리의 체력·남은 재생성 시간을 저장한다. 체력 0은 "처치와 지급이 끝남"을 뜻하므로 재화와 적 상태가 따로 기록되지 않는다. 자동저장(최대 1초 간격)은 같은 틱의 두 값을 함께 쓴다.
- 불러오면 살아 있는 일반 적은 출현 지점에서 남은 체력으로 대기하고, 처치된 적은 남은 재생성 시간과 함께 처치 상태로 남는다. 불러오기를 몇 번 반복해도 적·엽전이 다시 생기지 않는다.
- v1·v2 저장은 다른 진행을 모두 유지하고 일반 적을 1회차·6마리 생존으로 이행한다.
- 수련장 중에는 기존대로 저장을 거부하므로 수련 상태가 본편 저장을 덮어쓰지 않는다.
- 형식 세부는 [저장 정책](SAVE_SYSTEM.md).
