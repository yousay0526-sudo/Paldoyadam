# 캐릭터 모션 재제작 제안 · 움직임 우선, 파트별 검토

2026-10-22. 사용자는 사실적인 움직임을 조작감과 흥미의 핵심으로 지정했고, 신발/바지/상의/벨트/투구/무기로 나눠 디테일을 검토하는 방식을 제안했다. 이 문서는 조사와 제작 제안이다. 새 몸/장비/모션을 구현하거나 게임에 적용한 결과가 아니다. 기존 PR #41의 투사 시제품은 계속 미술 불채택 상태다.

## 추천하는 제작 경로

**실사 보행 자료 → 공통 성인 체형/골격의 보행 → 부품별 장비/천 제작 → Blender에서 방향별 2D 출력 → 기존 게임 표시 연결** 순서로 진행한다. 기존 승인 원화는 성인 비율·얼굴·장식·의상 실루엣·붉은 천 허리띠의 외형 참고로 유지한다. 한 장의 원화를 거친 전체 볼륨에 투사해 늘이는 방법은 재사용하지 않는다. 실제 조형과 각 면의 재질이 필요하다.

- 공통 몸/골격/카메라/모션을 모든 장비 제작의 기준으로 삼는다. 파트별 제작은 각각 다른 비율/동작으로 제작한다는 의미가 아니다.
- 몸은 실제 사람의 보행 자료를 기반으로 저작한다. 원본 보행을 그대로 옮겨도 체형 차이, 발 미끄러짐, 오른손 검의 무게/쥠은 보정해야 한다. 모션캡처 사용만으로 자연스러움이 보장되지는 않는다.
- 검/갑옷판/장화 밑창/투구는 재료에 맞게 형태를 유지한다. 갑옷판은 연결부에서 움직이고 천의 표면처럼 늘어나지 않는다.
- 소매/바지/옷자락의 접힘은 조형한 기본 주름과 관절별 보정 형상으로 먼저 저작하고, 필요한 느슨한 천에만 충돌/천 시뮬레이션을 검토한다. 상세한 주름이 없는 메시를 전신 가중치로 변형하는 것으로 대신하지 않는다. 결과는 프레임으로 미리 굽기 때문에 게임 안에서 천 물리를 실행할 필요는 없다.
- 파트별 게임 장비 합성은 후속 독립 작업이다. 단순히 PNG를 일정 순서로 겹치면 팔/소매/검의 앞뒤가림이 틀어질 수 있다. 공통 장비 공간, 앞뒤가림/마스크, 다른 상하의 사이의 겹침을 확인한 뒤 출력·합성 계약을 확정한다. 모든 장비 조합에 새 원화를 만드는 방식은 목표로 삼지 않는다.

## 파트별 순서와 확인 항목

| 순서 | 범위 | 눈으로 확인할 기준 |
| --- | --- | --- |
| 0 | 성인 비율 몸 + 검의 단순한 무게/손잡이 기준 형태 | 접지→체중 이동→발 회수, 절제된 상체 움직임, 오른손 쥠과 검을 든 팔의 자연스러움 |
| 1 | 신발 | 뒤꿈치 착지·발바닥 지지·발끝 이탈, 지지 중 미끄러짐, 신발 길이/밑창 형태 유지 |
| 2 | 바지 | 허리 위치 유지, 무릎 앞뒤의 압축/주름, 허벅지·정강이 길이가 늘어나 보이지 않음 |
| 3 | 상의: 안쪽 천과 바깥 갑옷판 구분 | 팔꿈치/겨드랑이의 국부 접힘, 어깨판 연결, 갑옷 무늬가 고무처럼 늘어나지 않음 |
| 4 | 붉은 천 허리띠 | 허리를 감싼 부분은 안정적, 늘어진 끝만 제한적으로 반응, 몸통 전체가 출렁이지 않음 |
| 5 | 투구 슬롯 | 머리와 함께 안정적으로 움직임, 성인 머리 비율과 기존 외형 방향 유지. 새 투구 디자인 제작은 별도 검토 |
| 6 | 최종 무기 디테일 | 실제 검신·손잡이·코등이 형태와 손가락 쥠, 길이/두께 유지, 손목 궤적과 오른손 고정 |

무기는 마지막까지 빠져 있는 것이 아니다. 0단계부터 손잡이/검의 기준 형태로 자세를 검토하고 마지막에 외형 디테일을 완성한다. 각 파트는 앞서 통과한 보행 위에서 개별 검토한 다음 합친다.

## 첫 번째 독립 제작 단위 제안

몸과 간단한 신발의 보행 한 종류, 오른손 검의 기준 형태까지만 제작한다. 표정/갑옷 장식/8방향/장비 양산은 이 단계의 범위가 아니다.

- 후보: CMU Subject 7의 01 일반 보행과 04 느린 보행. 공식 분류를 확인했으며 아직 파일 다운로드/재타기팅/품질 비교는 하지 않았다. 하나를 먼저 선택해 체형에 맞춰 보정한다.
- 앞/옆/대각 고정 카메라에서 2–3초짜리 실제 출력으로 접지·무게 이동·손목/검을 확인한다. 뼈/수치 검사와 별개로 사람이 보기에 자연스러운지를 검토한다.
- 발을 처음 딛는 자세, 체중을 받는 자세, 반대 발을 통과시키는 자세를 정지 화면으로도 비교한다. 몸만 자연스럽게 걷는 단계가 통과하기 전에 옷/갑옷의 세부 제작을 확대하지 않는다.
- 큰 미리보기와 실제 게임 표시 크기로 모두 검토한다. 출력 프레임 수는 이 비교 뒤 결정한다. 24프레임을 만들었다는 사실만으로 품질 통과로 간주하지 않는다.

## 조작감과 게임 연결에서 유지할 것

실제 확인한 코드: `src/game.h`의 `HERO_SPEED=155`, `HERO_WALK_DISTANCE=112`; `src/game.c`의 `game_hero_frame`과 실제 충돌 처리 뒤의 `walk_cycle`; `src/draw.c`의 `gfx_hero` 방향별 원본 셀 선택. 이동할 때의 실제 거리로 프레임을 진행시키며 벽에 막혀 이동하지 않으면 제자리 발 구름을 재생하지 않는다.

- 입력·충돌·이동은 기존 게임이 결정하고 애니메이션이 그 결과를 따른다. 자연스러운 영상 때문에 입력 시작/멈춤이나 공격 전환을 한 주기 끝까지 기다리게 하지 않는다.
- 현재 최고 속도에서 112/155, 약 0.723초에 한 주기가 진행된다. 1초짜리 Blender 미리보기와 재생 속도가 다를 수 있다. 이후 게임 표시 연결 단계에서 실제 보폭/체형/이동 거리와 재생 속도를 함께 검증해야 한다. 이 문서에서 상수나 게임 코드를 바꾸지는 않는다.
- 기존 8방향, 오른손 무기, 평타/기술 타이밍·입력 버퍼·콤보·이동/후퇴·NPC/퀘스트/맵은 유지한다. 시작/정지/방향 전환/공격 전환의 추가 시각 모션은 연결 단계에서 별도 검토한다.

## 조사한 자료와 비용

- [CMU 공식 모션 자료와 사용 안내](https://mocap.cs.cmu.edu/): 공식 안내는 상용 제품 내 데이터 포함을 허용하고 원본/변환 데이터 자체의 재판매는 금지한다. 무료 자료이며 이번 조사에서 유료 도구/서비스를 구매하지 않았다.
- [CMU Subject 7](https://mocap.cs.cmu.edu/search.php?subjectnumber=7), [공식 보행 분류](https://mocap.cs.cmu.edu/search.php?maincat=3&subcat=2): 01 일반 보행, 04 느린 보행 후보. 과장된 보행 분류는 첫 기준으로 삼지 않는다. 후보 이름/권리 안내 확인이며 실제 모션 품질 통과가 아니다.
- [Blender 공식 천 고정/형상 설정](https://docs.blender.org/manual/id/4.5/physics/cloth/settings/shape.html): 고정 부위와 나머지 천의 반응을 분리하는 데 참고한다. [Blender Studio의 무게 이동/보행 교육 목차](https://studio.blender.org/training/animation-fundamentals/chapter/5d710400b27563d4c15b0876/)도 확인했지만 유료 강의 접근이나 수강은 하지 않았다.

Spine이나 유료 의상 도구를 이 제작 경로의 필수 조건으로 삼지 않는다. AI 이미지 생성은 외형 참고/재질 제작을 돕는 용도로 검토하되, 순서대로 생성한 그림이 같은 신체/장비/동작을 유지한다고 가정하지 않는다. 이번 단계의 산출물은 이 제안서뿐이며, 새 보행/옷 주름/장비 조합을 구현했다고 주장하지 않는다. main 병합·배포 없음.
