# HUD 아이콘 원화 의뢰서 (보따리 · 탕약 · 지혈산)

2026-10-28 · PR #48 후속. 사용자 검토 결과 코드로 그린 보따리(가방)는 "커피 같다", 탕약·지혈산은 "너무 투박하다"는 의견이라 그림을 빼고 자리만 남겼다. 이 세 아이콘은 **그림 파일(PNG)만 넣으면 코드 수정 없이** 게임에 나온다.

## 지금 상태
- 버튼 위치·크기·동작·단축키는 그대로다. 가방 버튼(우측 상단, 엽전 소지금 오른쪽), 탕약·지혈산 버튼(우측 하단, 공격 원 왼쪽 열)의 **아이콘 자리만 비어 있고** 탕약·지혈산은 개수 숫자만 보인다.
- 엽전(소지금), 전체화면, 일시정지, 하트(체력), 무공(교차한 칼)은 코드로 그린 아이콘을 유지한다. 이번 의뢰 범위가 아니다.

## 넣을 파일
| 파일 | 내용 | 버튼 |
|---|---|---|
| `assets/ui/icon-bag.png` | 보따리(천으로 싸서 위를 묶은 짐 보따리). 가방 메뉴를 연다 | 우측 상단 44×44 |
| `assets/ui/icon-tonic.png` | 탕약(한약). 사발이나 약탕기 등 한약임이 보이게. 체력 회복 | 우측 하단 78×44, 오른쪽에 개수 |
| `assets/ui/icon-bandage.png` | 지혈산(출혈을 멎게 하는 가루약). 약첩·약봉지 등. 출혈 치료 | 우측 하단 78×44, 오른쪽에 개수 |

## 규격
- PNG, RGBA, **배경 완전 투명**. 정사각형 권장 **128×128**(다른 비율도 긴 변 기준으로 맞춰 그림).
- 화면에서는 긴 변이 약 **24px**로 줄어 그려진다(선형 보간). 작게 줄여도 형태가 읽히도록 실루엣을 크고 단순하게, 가는 선·작은 글씨는 피한다. 가장자리 여백 4px 정도.
- 버튼 바탕이 어두운 청록(`#152728` 근처)이므로 밝은 색·외곽선으로 대비를 준다. 게임 원화(조선풍, 따뜻한 갈색·금색 계열)와 어울리게.
- 사용할 수 없을 때(체력 가득·개수 0 등)는 코드가 그림을 자동으로 어둡고 반투명하게 만든다. 따로 흐린 버전을 만들 필요 없다.
- 피·상처 표현, 서양식 붉은 십자 표시는 넣지 않는다.

## 코드 연결 (이미 되어 있음)
- `src/draw.h` `UiIcon`, `UI_ICON_FILES` / `src/draw.c` `gfx_load`: 위 세 경로를 선택적으로 읽는다. 파일이 없어도 게임은 정상 실행된다.
- `src/main.c` `hud_icon`: 그림이 있으면 버튼 중앙(탕약·지혈산은 숫자 왼쪽)에 비율을 유지해 그린다.
- 웹(`scripts/build_web.py`)과 네이티브 빌드는 `assets/` 폴더를 통째로 포함하므로 추가 설정이 필요 없다.

## 확인 방법
```sh
cmake -S . -B build && cmake --build build
ctest --test-dir build --output-on-failure        # responsive_ui가 아이콘 자리·버튼 안 그리기를 검사
SDL_VIDEODRIVER=dummy ./build/paldo-yadam --smoke village.bmp --scene village --size 844x390
```
출력 화면에서 세 아이콘이 버튼 안에 보이는지, 844×390(휴대폰)과 1280×720에서 알아볼 수 있는지 확인한다. 전후 비교 이미지는 `docs/hud-icons-review.png`.
