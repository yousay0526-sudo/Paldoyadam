## 원화 제작 당시의 검수 이력

내장 ImageGen을 사용했다. Windows 로컬 참조 경로 전달은 `AbsolutePathBuf deserialized without a base path` 오류로 생성 전 거부되어, 먼저 직접 열어 확인한 같은 마을 이미지를 대화 이미지 참조로 전달해 재시도했다. 실패한 호출은 완성본으로 세지 않는다. 재시도에서 독립된 배경 3장이 반환됐다. 별도 샤픈·합성·리샘플·색 보정은 하지 않았다.

요청한 캔버스는 가로 3:2, 1536×1024이다. 출력 화면은 이 구성으로 확인했지만 파일 바이트를 내려받아 IHDR·색 모드·SHA-256을 확인하지 않았으므로 실행 규격 검증 완료로 표시하지 않는다. 사과는 오른쪽 아래의 매우 작은 소품으로 눈으로 확인했다. 크기와 좌표는 실제 PNG 설치 시 실측한다.

육안 확인 항목: 기존 청록 숲/흙색/따뜻한 등불 계열, 동일 계열 내려다보기 시점, 마을 북쪽/동쪽 출구 분리, 솔바람재의 높낮이와 여러 진입길, 탐식굴 중앙 전투 여백, 건조한 포식 흔적과 작은 사과, 혈흔과 배경 인물 부재.

미검증: 캐릭터 합성 후 배율과 가림, 이동 가능 영역의 연속성, 충돌·카메라/목적지 탭·전환 좌표, 실제 게임에서의 적 출현과 보스전, SDL/CTest/웹/모바일. 배경 원화만 생성했고 저장소 실행 파일을 변경하지 않아 게임 테스트는 실행하지 않았다.

## 원화 단계에서 정한 연결 경계 · 현재 구현은 MAP_INTEGRATION.md 참조

사용자 원화 검토 후 별도 작업으로 진행한다. 기존 마을 원본은 1536×1024, 월드는 2304×1536이나 이번 새 배경도 자동으로 같은 월드/충돌에 맞는다는 뜻은 아니다. `WORLD_SOLIDS`/`WORLD_COVERS`는 기존 그림 기준의 수동 다각형이므로 새 그림에 맞춰 독립적으로 작성·검증해야 한다. 단순 `assets/village.png` 덮어쓰기는 적합한 연결 방법이 아니다.

다음 담당자는 PNG 원본/규격 확보 → 새 맵별 충돌·가림/출입 지점 제안 → 사용자 승인 범위 안에서 맵 전환·NPC·잡몹/백정 연결 → 기존 이동/전투/퀘스트와 웹·모바일 회귀 순서로 범위를 나눠 진행한다. 이 기록은 그 구현을 승인하거나 완료했다고 뜻하지 않는다. 기존 다른 브랜치와 미술 작업은 수정하지 않았다. `GAME_BIBLE.md`는 main에서 찾을 수 없어 생성하지 않았다. 병합·배포·버전 변경 없음.
