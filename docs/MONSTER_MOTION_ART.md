## 생성물

내장 ImageGen으로 기존 그림을 참조하여 제작했다. 생성 원본·전체 프롬프트·교정 프롬프트를 `art/monsters/`에 보존했다. 원본 위에 프레임을 덮어쓰지 않는다. 피·혈흔·피 입자는 요청하지 않았고 리뷰에서 별도 혈흔 이펙트가 없음을 확인했다. 백정의 가죽끈·허리 천·앞치마 해짐을 색상 필터로 지우지 않았다. 주인공 에셋은 변경하지 않았다.

| 원화 | 수량 / 실제 크기 | 배열 |
| --- | --- | --- |
| 돼지 방향표 | 1장 / 1225×1284 RGBA | 3×3, 가운데 빈칸: NW N NE / W 빈칸 E / SW S SE |
| 백정 방향표 | 1장 / 1286×1223 RGBA | 같은 배열 |
| 돼지 걷기·공격 | 각 2장 / 1254×1254 RGBA | 4열×4행, 각 행의 네 포즈가 한 방향 |
| 백정 걷기·공격·내려찍기 | 각 2장 / 1254×1254 RGBA | 같은 배열 |

모션 원화의 `0`은 N/NE/E/SE, `1`은 S/SW/W/NW다. **총 12장, 정지 16 + 모션 160 = 176포즈**다. 돼지 공격은 웅크림→머리 낮춤→엄니 전진→회수, 백정 공격은 짧은 허리 높이 베기, 스킬은 머리 위 들기→버팀→내려찍기→수습으로 구분한다. 백정은 오른손 식칼과 빈 왼손을 기준으로 독립 방향 그림을 생성했다. 가려진 손은 보이는 팔·어깨·무기 위치를 기준으로 시각 검토했으며 3D 골격 검증은 아니다.

## 비파괴 준비와 후속 표시 계약

`python scripts/prepare_monster_assets.py` (Pillow)가 아래 **후보** 7장을 `art/monsters/prepared/`에 만든다. 아직 `assets/`나 웹 사전 로딩 목록에 넣지 않았으므로 게임 다운로드·텍스처 메모리는 늘어나지 않는다.

- `boar-idle-8dir-v1.png`, `butcher-idle-8dir-v1.png`: 768×384, 192px 셀 4×2, N/NE/E/SE/S/SW/W/NW 순.
- `boar-walk`, `boar-attack`, `butcher-walk`, `butcher-attack`, `butcher-skill`의 `-8dir-v1.png`: 각각 768×1536, 192px 셀 4열×8행. 행은 N/NE/E/SE/S/SW/W/NW, 열은 네 동작 단계다.
- 실제 알파를 검사하고 연결된 실루엣을 선택한다. 알파 16 초과 연결 성분에 1px 안티앨리어싱 여유를 보존하고, 알파 1..4의 미세 잡점만 제거한다. 배경색 제거·색 교체·반전·보간 프레임 추가는 없다. 축소는 알파 사전 곱 Lanczos다.
- 공통 발 기준점은 셀의 `(96,176)`. 원본 몸통 중간의 중앙 열과 가장 낮은 실루엣을 이용한 **임시 픽셀 기준점**이다. 몸의 비틀림·칼이 발보다 낮은 포즈는 실제 게임 크기에서 추가 미술 조정이 필요할 수 있다. 골격 기반 고정이나 완전한 발 미끄러짐 제거를 뜻하지 않는다.
- 각 방향의 네 포즈에 같은 비율을 적용한다. 넓은 식칼·돌진 포즈를 셀 안에 넣기 위해 축소한 경우 `preparation.json`의 `draw_scale_compensation`을 표시 시 적용해야 몸이 작아지지 않는다. 후속 렌더러는 **발 기준점과 셀별 배율을 함께 사용**해야 한다. 단일 고정 사각형에 모든 행동을 맞추면 안 된다.
- `preparation.json`에 원본/후보 SHA-256, 실제 크기·알파, 원본 선택 경계·기준점·배율, 각 셀 해시·반전 없음 기록을 남겼다.

최초 돼지 걷기 `0` 시트의 E방향 오른쪽 포즈에서 주둥이 경계 잘림을 발견했다. ImageGen 편집으로 포즈 여백과 주둥이를 교정한 원본으로 교체하고 같은 검사를 다시 통과했다. 잘린 초안을 최종 원화로 포함하지 않았다.
