# 길목 이정표와 열린 동쪽 출구 · 2026-10-28

마을→탐식굴 길의 닫힌 문처럼 보이는 그림을 열린 흙길로 고치고 원형 이동 표식을 물리적인 길안내 소품으로 바꿨다. PR #47 사용자 검토 후 작은 글씨, 동쪽 소품 중복과 동굴의 나무 이정표를 다시 수정했다.

## 최종 동작과 변경 파일

- `assets/maps/village.png`: 동쪽 길의 ImageGen 부분 편집. 35,172픽셀 변경, x1330..1535/y545..719 밖 0픽셀 변경. 이번 검토 수정에서 배경 자체는 더 바꾸지 않았다.
- `src/draw.c/h`, `assets/maps/waypost.png`: 나무 방향판을 기둥 비율과 별도로 넓혀 목적지 글자를 16 붓글씨에서 굵은 명조 26으로 키웠다. 0.6 단위 덧그리기로 획을 보강한다. 텍스트 영역도 83×21에서 122×35로 넓혀 자동 축소를 줄였다.
- 마을 북쪽/솔바람재 귀환은 나무 이정표, 마을 동쪽은 **배경의 기존 등주에 방향판만 부착**한다. 별도 기둥과 등롱을 추가하지 않아 배경 소품과 중첩하지 않는다.
- `assets/maps/cave-waystone.png`: 탐식굴의 나무 소품은 제거하고 입구 왼쪽 바위와 맞는 낮은 청회색 표지석으로 바꿨다. 표면에 크기 28의 밝고 굵은 ‘마을’ 글자와 작은 아래 화살표를 표시한다. 새 RGBA 텍스처 로드/실패 검사/해제를 연결했다.
- `src/maps.c`, `art/maps/layout.json`: 동쪽 기존 등주와 동굴 표지석 위치에 맞춰 두 충돌 footprint를 갱신했다. 출구 판정·거리·도착 좌표·상호작용 버튼/Space·퀘스트·전투 규칙은 그대로다. 발 위치 순서로 그린다.
- `src/main.c`: `--scene exit0`..`exit3`은 마을→솔바람재, 마을→탐식굴, 솔바람재→마을, 탐식굴→마을을 출력한다.

## 실제 검증

사용자 검토 반영 후 Windows / Zig 0.14.1 / SDL 2.32.10 전체 빌드 성공, CTest **12/12 통과 (15.92초)**. 수정된 소품 충돌을 포함한 왕복·의뢰 전체 흐름·자원 보존·실제 SDL 입력과 기존 전투/수련/UI/주인공·몬스터 렌더를 재검사했다. 네 출구를 844×390과 1280×720으로 각각 실행 출력하고 글자 가독성·소품 배치를 검토했다.

## 복구와 경계

동굴 원화는 예상 1280과 달리 1254×1254였다. 준비 스크립트가 잘못된 크기에서 중단되어 실제 IHDR을 확인하고 정규화 크롭으로 수정했다. 첫 전체 빌드는 실행 시간 제한으로 링크 일부가 남았고 증분 빌드로 완료한 후 전체 테스트를 실행했다. 제품 소스 오류를 감추거나 중간 결과를 성공으로 기록하지 않았다.

GAME_BIBLE.md는 없어 생성하지 않았다. 일반 적 재등장 등 다른 독립 작업·정식 버전 변경·main 병합·배포 없음.
