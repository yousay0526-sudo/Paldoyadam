# 주인공 8방향·오른손 기준 원화 검토

이 문서는 8방향 표시를 위한 원화 검토 단계다. 실행용 정지/걷기/공격 시트를 구현하거나 게임에 연결한 결과가 아니다.

## 현재 코드에서 확인한 것

- 기준 main: `07f39936cddc56c5091fa0b6a973b5e765789b5a` (기술 전용 원화 PR #14 병합·배포 이후).
- `Hero.dir`는 이미 2차원 벡터다. `game_tick`은 입력 길이를 정규화하고 이동/지형 충돌 결과로 발걸음 주기를 진행한다. 대각선 이동 속도를 새로 바꾸거나 맵/충돌을 재구성할 필요가 없다.
- `Hero.face`와 `attack_face`는 현재 좌/우 두 값이다. `gfx_hero`가 `SDL_FLIP_HORIZONTAL`로 원화를 반전하므로 칼 든 손까지 바뀐다. `Hero.dir`의 위/아래 성분은 현재 캐릭터 시점에 반영되지 않는다.
- 공격은 시작 시 정한 `attack_angle`/`skill_angle`과 `attack_face`를 별도로 보관한다. 이동 방향과 공격 방향을 같은 순간값으로 덮어쓰면 기존 고정 공격 방향과 충돌할 수 있으므로 분리해서 연결해야 한다.

## 원하는 표현

고정된 현재 카메라에서 인물 전체가 8방향으로 돌아가는 2D 원화를 사용한다. 정지·걷기·평타·4무공 모두 같은 해부학적 오른손에 칼을 들어야 한다. 왼손은 비우고 칼집은 왼쪽 허리에 둔다. 반대 방향 그림을 단순 반전해 만들지 않는다.

정면에서는 오른손이 화면 왼쪽에, 뒷모습에서는 화면 오른쪽에 나타난다. 옆모습에서 오른팔이 몸 뒤에 있는 방향은 자연스럽게 가려져야 하며, 잘 보이게 하려고 왼손으로 칼을 옮기지 않는다. 뒷모습은 얼굴만 뒤로 돌리지 않고 등 갑옷·어깨 뒤·뒤통수·발 방향을 모두 맞춘다.

원화 시트는 중앙을 비운 나침반 배치로 검토한다. 현재 결과는 참고 일러스트 시트이므로 균일한 셀 분할이나 공통 발 기준점이 맞춰진 실행용 아틀라스로 취급하지 않는다.

| 왼쪽 열 | 중앙 열 | 오른쪽 열 |
| --- | --- | --- |
| 북서 NW: 왼쪽 뒤 대각선 | 북 N: 뒷모습 | 북동 NE: 오른쪽 뒤 대각선 |
| 서 W: 왼쪽 옆모습 | 비움 | 동 E: 오른쪽 옆모습 |
| 남서 SW: 왼쪽 앞 대각선 | 남 S: 정면 | 남동 SE: 오른쪽 앞 대각선 |

그림 기준은 기존 승인 주인공이다. 상투·수염·남색/청록 갑옷·금 장식·흰 깃·붉은 천 허리띠·장화·은색 환도를 유지한다. 혈흔·피 입자를 추가하지 않는다. 새로 보이는 등 갑옷의 구체적 묘사는 이번 검토 대상이며 아직 승인된 정본으로 취급하지 않는다.

![8방향 기준 원화](../art/hero/directions/eight-direction-master.png)

실제 생성 master는 1254×1254 RGBA다. 초기 프롬프트와 북서 포즈 교정 프롬프트를 같은 폴더에 보존했다. 시각 검토 후 오른손·빈 왼손·칼집 관계를 교정한 결과이며, 방향별 애니메이션 제작에 앞서 사용자의 미술 검토를 받는다.

## 적용 작업을 나누는 기준

1. 이번 단계: 8방향 정지 기준 원화로 오른손과 앞/뒤/옆/대각선의 일관성을 검토한다.
2. 기준 승인 후: 방향별 정지·걷기 시트, 마지막 정지 방향 유지, 대각선 방향 전환과 공통 발 기준점을 연결하고 이동/입력/가림 회귀를 검사한다.
3. 이동 단계 검토 후: 평타와 4무공을 같은 방향/오른손 기준으로 확장한다. 기존 공격 방향 고정·0.64초 기술/0.24초 타격·버퍼/콤보·전진/후퇴·히트스톱을 보존하고 공격/렌더링 회귀를 검사한다.

기존 정지·걷기·공격을 일괄 8방향으로 만드는 데는 각 동작별 원화가 필요하다. 이 한 장만으로 걷기나 검술 애니메이션이 완성되는 것은 아니다. 실제 3D 모델에서 방향별 2D 프레임을 렌더링하는 제작 방식도 가능하지만, 별도의 모델링·리깅·애니메이션 제작 범위다. 현재 단계는 기존 2D 게임에 맞는 방향별 원화 검토다.

이번 단계에서는 제품 코드·기존 실행 PNG·맵/충돌·NPC/퀘스트·배포 설정을 변경하지 않는다. 다음 독립 단계는 저장소 `AGENTS.md`의 작업 단위별 승인 규칙에 따른다.
