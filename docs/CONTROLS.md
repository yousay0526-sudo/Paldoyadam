# 팔도야담 조작 경험

## 0.7에 반영한 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 / 화면 끌기 | 이동 |
| Space / Enter | NPC 대화·조사·상점, 다음 대사, 프롤로그 진행 |
| E | 기존 대화·조사·상점 입력도 유지 |
| 가까이 이동 | 반경 156 안의 약재가 자동으로 끌려와 거리 16에서 획득 |
| F (PC 보조 입력) | 기존 반경 70 이내 즉시 회수 유지 |
| Q / 갈라베기 버튼 | 액티브 스킬 |
| J / 왼쪽 위 여정 표시 | 상세 퀘스트 기록 |
| I / 가방 버튼 | 장비와 물품 확인 |

자동 회수는 이동을 중단하지 않는다. 벽 너머 물품은 끌어오지 않으며 중복 획득을 막는다. 별도 줍기 버튼은 제거했다. 대화·메뉴·일시정지 중에는 물품 이동과 획득도 멈춘다. 스페이스 키의 자동 반복으로 대사를 건너뛰지 않는다.

퀘스트는 왼쪽 위 290×52 이하의 둥근 패널에 현재 목표·수량을 표시한다. 알림은 그 아래 한 줄, 최대 316×29, 2.8초로 제한하고 페이드로 나타나고 사라진다. 상세 설명은 여정 기록에 둔다. 제목과 인물명은 나눔붓글씨, 본문은 나눔명조 Bold이며 버튼은 글자의 실제 경계로 중앙 정렬한다.

## 4번 조작 실험 제안 — 사용자 요청으로 보류

아래는 이전 아이디어 기록이며 0.7 구현 범위에 포함하지 않는다.

목표는 쉽게 시작하고 방향·간격·타이밍을 익힐수록 더 잘 싸울 수 있는 조작이다. 각 요소의 전례가 없다고 단정하지 않는다. 조선 검술의 발놀림과 아래 요소들을 일관되게 결합하는 방향을 제안한다.

### 1. 누르고 방향을 잡아, 놓으며 베기

터치에서는 스킬 버튼을 누른 채 끌면 칼이 나갈 방향과 짧은 이동 궤적을 얇게 보여 준다. 놓으면 그 방향으로 공격한다. 짧게 누르면 현재 바라보는 방향으로 발동한다. PC에서는 Q를 누른 상태에서 마우스로 방향을 정하고 Q를 놓을 때 발동하는 방식을 시험한다.

초보자는 한 번 누르는 기존 조작으로도 싸운다. 익숙해지면 적의 측면·거리·두 적의 겹침을 보고 방향을 선택한다. 취소 영역과 Escape 취소를 두어 준비 동작이 공격을 강요하지 않도록 한다. 조준 중 시간 정지 여부는 난이도 옵션으로 검토하며 멀티플레이를 전제로 하지 않는다.

### 2. 짧게 비켜서고, 다음 공격으로 연결

별도의 회피 버튼을 짧게 누르면 이동 방향으로 한 보 물러난다. 길게 누르거나 두 번 탭해야만 기본 회피가 나가도록 만들지 않는다. 모바일의 이동 손가락을 빠르게 튕기는 동작은 선택 가능한 추가 입력으로만 시험한다. 빠른 방향 전환과 회피가 혼동되면 제거한다.

적의 공격 직전에 피하면 잠깐 다음 방향 베기의 준비 시간이 줄어들게 한다. 초보자는 생존하고, 숙련자는 공격 리듬을 이어 간다. 회피 거리·무적 시간·보상 창은 플레이 테스트에서 정하고 벽과 위험 지형 판정은 유지한다. 기존의 출혈·돌진 밸런스를 함께 검토해야 한다.

### 3. 입력을 받아 주되, 의도를 바꾸지 않기

공격 종료 직전 약 100~150ms에 누른 다음 입력을 잠시 저장해 가능한 첫 순간 실행하는 방안을 시험한다. 이 수치는 초기 실험값이다. 대화·상점·가방이 열리거나 입력을 취소하면 예약을 지운다. 자동 공격이 원하지 않는 방향으로 새 입력을 덮어쓰지 않게 한다.

대상 보정은 바라보는 방향의 가까운 적으로만 제한하고 선택 대상을 작게 표시한다. 플레이어가 조준을 바꾸면 즉시 해제하며 보정을 끄는 옵션을 둔다. 캐릭터가 적을 향해 갑자기 반 바퀴 돌거나 벽 너머 대상을 선택하면 실패로 간주한다.

### 먼저 시험할 순서

1. 방향 베기를 단독으로 붙여 현재 Q 스킬과 비교한다.
2. 기본 회피 한 가지를 추가하고 실수 발동 여부를 본다.
3. 둘이 안정되면 입력 예약과 정확한 회피 보상을 얹는다.

짧은 동일 전투에서 잘못 나온 동작 수, 다시 누른 입력 수, 벽에 걸린 횟수, 모바일 양손 피로를 기록한다. 10분 안에 기본 조작을 이해하는지, 30분 뒤에는 방향과 타이밍으로 더 잘 싸우는지 함께 본다. 새로움만으로 조작이 편하다고 판단하지 않는다.
